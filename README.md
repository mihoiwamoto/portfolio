# UI/Webデザイナー ポートフォリオサイト

WEBデザイナー向けのポートフォリオサイトです。

## 構成

- `index.html` - メインHTMLファイル
- `styles.css` - スタイルシート
- `script.js` - JavaScript（スムーススクロール、フォーム処理）
- `images/` - 画像フォルダ

## セクション

### 1. Profile（プロフィール）
- 名前
- 肩書き：UI/Webデザイナー
- 自己紹介文
- スキルセット（Figma、Illustrator、Photoshop等）
- プロフィール画像（アーチ型フレーム）

### 2. Works（実績・作品）
- 作品画像
- プロジェクト名・URL
- 制作期間
- こだわり・解決した課題

### 3. Contact（お問い合わせ）
- お問い合わせフォーム
  - 名前（必須）
  - メールアドレス（必須）
  - 件名（必須）
  - お問い合わせ内容（必須）

## 必要な画像

以下の画像を `images/` フォルダに配置してください:

1. `profile.jpg` - プロフィール画像（アーチ型フレーム用）
2. `work1.jpg` - 作品1のスクリーンショット
3. `work2.jpg` - 作品2のスクリーンショット
4. `work3.jpg` - 作品3のスクリーンショット
5. `work4.jpg` - 作品4のスクリーンショット

推奨サイズ:
- プロフィール画像: 700×900px（縦長）
- 作品画像: 1200×800px（横長）

## 表示方法

1. 上記の画像を `images/` フォルダに配置
2. `index.html` をブラウザで開く

## デザインの特徴

- **Profileセクション**: グレーブルーの背景、アーチ型フレームのプロフィール画像
- **Worksセクション**: 2カラムグリッドレイアウト、ホバーエフェクト付きカード
- **Contactセクション**: ブルーグレーの背景、シンプルなフォーム
- 固定ヘッダーナビゲーション（スムーススクロール対応）
- レスポンシブデザイン対応（モバイル最適化）

## カスタマイズ方法

### プロフィール情報の変更
[index.html](index.html) の以下の部分を編集:
- 名前: `.profile-name`
- 肩書き: `.profile-title`
- 自己紹介: `.profile-description`
- スキル: `.skill-tag`

### 作品情報の変更
各 `.work-item` の内容を編集:
- プロジェクト名
- URL
- 制作期間
- こだわり・解決した課題

### 色の変更
[styles.css](styles.css) で以下の色を変更可能:
- メインカラー: `#6b7b8c`（グレーブルー）
- サブカラー: `#8a9ba8`（ライトブルーグレー）
- アクセントカラー: `#d4c4b0`（ベージュ）

### お問い合わせフォームの送信処理
[script.js](script.js) の `contactForm.addEventListener` 内に、実際の送信処理を実装してください。
（例: EmailJS、Formspree、サーバーサイドAPIなど）
